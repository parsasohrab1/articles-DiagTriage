# Business Requirements Specification – DiagTriage

| ID | Requirement |
|----|-------------|
| BR-1 | Route each case either to automatic handling (one confident label) or to an expert. |
| BR-2 | Guarantee the coverage of the pathologic class, not only the average coverage. |
| BR-3 | Report the expert workload (referral rate) that each guarantee costs. |
| BR-4 | Report real-data results only; no claim of clinical use. |

Out of scope: deployment in obstetric care, regulatory approval, prospective evaluation.
